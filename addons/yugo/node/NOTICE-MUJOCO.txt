Linux GLFW bundles both X11 and Wayland libraries. The source loader extracts
only this host's engine and GLFW wheels plus the six pure Python dependencies;
it keeps Blender's NumPy. Inside Blender, the Linux default GLFW import selects
the library beside its resolved Python package, honors explicit PYGLFW_LIBRARY
and PYGLFW_LIBRARY_VARIANT settings, and restores its temporary environment
setting. It does not change MUJOCO_GL or disable rendering for other consumers.
Yugo uses CPU simulation, without creating a MuJoCo window or render context.

The official wheels retain their original component licenses and notices.
This attribution does not replace those license texts. Blender's NumPy is
used without replacing it. The Windows adapter retains the upstream engine
and uses official paired allocation callbacks with 64-byte-aligned UCRT
allocation when the Blender host requires it.

Yugo generates MJCF from explicitly selected rigid bodies and VRM Spring Data.
No humanoid template, learned controller or model asset is included here.
MuJoCo and its Python bindings are not an officially supported Google product.

Yugo Node can also reuse an already-loaded compatible official CPU MuJoCo
3.5.0 runtime. That runtime is not bundled in this archive.
