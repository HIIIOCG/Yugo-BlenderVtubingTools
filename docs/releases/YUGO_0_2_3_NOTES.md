## What's changed in 0.2.3

- **Rigid Body to YugoPhysics** — Rigid-body simulation now supported on Linux x64 and Apple Silicon Macs.
- **Spring to YugoPhysics** — VRM spring-bone physics for hair and clothing now supported on Linux x64 and Apple Silicon Macs.
- **YugoPhysics Solver** — Fixed Linux errors that prevented physics simulations from starting.

**Compatibility:** Blender 5.1 / 5.2 · Windows x64 · Linux x64 · Apple Silicon Mac.
