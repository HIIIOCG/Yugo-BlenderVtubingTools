## What's changed in 0.7.0

- **Message Source / Floating UI Display** — Display message text and local avatar images as animated rows using scene templates and anchors.
- **Prop Physics** — Apply forces and impulses, grab and release objects, and return them home without advancing the timeline.
- **Pose Source / Ragdoll Motion / Apply Ragdoll** — Turn a rig's pose into a live ragdoll, apply hits, and blend back to its captured pose.

**Compatibility:** Blender 5.1 / 5.2 · Existing Studio graphs retain their node and socket IDs. Stop other pose controllers before starting Ragdoll.
